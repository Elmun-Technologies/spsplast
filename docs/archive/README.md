saqlanadi. Ularda savat, checkout, to'lov (Click/Payme), admin panel va Prisma
haqida gap boradi — bu qismlarning barchasi 2026-10 da **butunlay olib
tashlangan** (`docs/OPTIMIZATION-LOG.md`, Batch 3).
